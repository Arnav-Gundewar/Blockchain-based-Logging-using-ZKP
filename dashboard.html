Step 02 — Commitment

Building
Merkle Trees

Each log entry is hashed with Poseidon. Pairs are combined upward into a single root — a fingerprint of the entire batch.

Step 03 — Immutability

Anchoring roots
on-chain

Each Merkle root is written to a smart contract on Ethereum Sepolia — timestamped and immutable. No log can be altered after this point.

Step 04 — Zero Knowledge

Generating
ZK Proofs

For each batch, a zk-SNARK proof is generated that the suspicious event count stays below threshold — without revealing which events triggered it.

Step 05 — Verification

On-chain
Verification

Each proof is checked by the Solidity verifier contract. The auditor learns only pass/fail — never the underlying log contents.
